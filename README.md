
# ABRISIA-PLAN.ca

ABRISIA-PLAN est bien plus qu’un simple site Web pour moi.

Je suis partie avec une idée, très peu de moyens et pratiquement aucune connaissance en programmation ou en développement Web.

Plutôt que d’abandonner le projet parce que je n’avais ni équipe de développeurs ni gros budget, j’ai décidé d’essayer quelque chose de différent : faire confiance à l’intelligence artificielle pour apprendre, comprendre, créer et avancer étape par étape.

Avec l’aide d’outils d’intelligence artificielle, de GitHub et de différentes plateformes de développement, je construis progressivement ABRISIA-PLAN.ca afin de pouvoir démarrer mon activité freelance.

ABRISIA-PLAN a pour objectif d’offrir des services de conception et de plans sur mesure pour différents types de projets : maisons, chalets, mini-maisons, rénovations, agrandissements, aménagements, optimisation des espaces et mobilier sur mesure.

Le projet prévoit également la création de modèles et de collections de plans pouvant être proposés directement en ligne.

Ce dépôt représente donc à la fois le code du projet et mon parcours d'apprentissage.

Je ne prétends pas être développeuse. Je suis une entrepreneure qui apprend à utiliser les outils disponibles aujourd’hui pour essayer de construire quelque chose à partir de presque rien.

L’objectif est simple :

**Transformer une idée en entreprise, apprendre en avançant et voir jusqu’où l’intelligence artificielle peut aider une personne ordinaire à créer quelque chose qui, auparavant, lui aurait semblé inaccessible.**

🌐 **Projet : ABRISIA-PLAN.ca**  
🏠 Plans et conception sur mesure  
🛠️ Projet construit progressivement avec l’aide de l’intelligence artificielle  
🚀 Une entreprise créée à partir de presque rien
